# PROMPT LIBRARY - TEMPLATES

> Usar estas plantillas solo despues de cargar el bootstrap canonico del work-kit.
> La plantilla no reemplaza reglas, sizing policy ni contexto temporal vigente.
> Reporting guidance: para LOW y MEDIUM risk, preferir operator output compacto; reservar full reporting para HIGH risk, REJECT, o bloqueadores sin resolver.
> Skill-aware guidance: si el prompt usa `USE REPO PROCEDURE: skills/<name>/SKILL.md`, delegar el formato con `FOLLOW THE PROCEDURE'S REQUIRED OUTPUT FORMAT` y no copiar la lista de secciones salvo formato custom justificado.
