# Archive

Use this folder for superseded handoffs, old reports, and historical docs that should remain accessible but no longer belong in active product docs.

## Typical Contents

- closed audit reports
- old prompt packs
- historical rollout notes
- retired architecture snapshots
- exported handoffs from previous phases

## Rules

- Do not add active canon here.
- Do not add product-facing current truth here.
- Archive before deleting whenever the material may still matter for traceability.
