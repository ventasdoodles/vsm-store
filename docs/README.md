# Docs Map

This folder is the internal documentation hub for VSM Store.

## Current Bands

- `product/` - product-facing truth, feature intent, productization notes
- `architecture/` - current system architecture and data-flow truth
- `operations/` - runbooks, validation, support, deploy-adjacent docs
- `ai-workflows/` - agent/work-kit/prompt policy
- `audits/` - current audit detail files
- `internal/` - docs that stay in-repo but are not product-facing
- `archive/` - superseded history kept for reference only
