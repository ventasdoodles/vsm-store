# VSM Store Audit Archives

This directory holds detailed accepted audit evidence after the canon split.

## Rules
- `AI_CONTEXT.md` stays current-state-first.
- `AUDIT_LOG.md` stays a compact chronological index.
- Detail files live under `docs/audits/YYYY-MM/`.
- Full pre-split snapshots live under `docs/archive/`.
- Do not create `AI_CONTEXT2.md` or `AUDIT_LOG2.md`.
- Preserve non-claims in both live summaries and detail files when they affect future work.
- A detail file may group related lanes when that preserves continuity better than fragmenting one operational story.
