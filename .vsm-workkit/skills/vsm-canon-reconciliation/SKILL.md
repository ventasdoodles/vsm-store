# VSM Store Procedure — Canon Reconciliation

## Required behavior

- Editar solo docs/canon autorizados.
- Preservar accepted facts.
- Preservar non-claims.
- Preservar residual risks.
- Validar docs-only diff.
- Commit/push si está autorizado.

## Output

1. FILES INSPECTED
2. FILES MODIFIED
3. EXACT FACTUAL UPDATES MADE
4. VALIDATION
5. COMMIT HASH + MESSAGE
6. PUSH RESULT
7. STATUS
