# VSM Store Procedure — Acceptance Audit

## Required behavior

- Confirmar repo state.
- Inspeccionar commit/diff.
- Verificar scope.
- Revisar evidencia.
- Separar claims/non-claims.
- Emitir verdict.
- No implementar.

## Verdicts

- ACCEPT
- ACCEPT WITH RESIDUAL RISK
- REJECT

## Output

1. REPO STATE
2. COMMIT / DIFF INSPECTED
3. SCOPE VERDICT
4. VALIDATION VERDICT
5. ACCEPTED CLAIMS
6. NON-CLAIMS
7. RESIDUAL RISKS
8. VERDICT
9. EXACT CANON PROMPT IF ACCEPTED
10. PROMPT QUALITY GATE CHECK: PASS/FAIL
