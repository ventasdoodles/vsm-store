# VSM Store Procedure — Readiness

## Purpose

Seleccionar el siguiente paso seguro y de mayor valor.

## Required behavior

- Confirmar repo state.
- Leer solo fuentes relevantes.
- Identificar baseline.
- Identificar non-claims.
- Clasificar riesgo.
- Elegir un best next move.
- Producir prompt exacto.
- No implementar.

## Output

1. FILES / SOURCES READ
2. CURRENT BASELINE
3. ACTIVE NON-CLAIMS
4. RISK CLASSIFICATION
5. BEST NEXT MOVE
6. WHY
7. TOOL THAT SHOULD ACT NEXT
8. EXACT NEXT PROMPT
9. GO / NO-GO
10. RESIDUAL RISKS
11. PROMPT QUALITY GATE CHECK: PASS/FAIL
