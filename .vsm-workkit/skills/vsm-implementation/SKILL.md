# VSM Store Procedure — Implementation

## Required behavior

- Verificar repo state.
- Editar solo scope autorizado.
- No rediseñar desde cero.
- Validar según prompt.
- Commit/push si está autorizado.
- Preservar non-claims.
- No self-acceptance.

## Output

1. PRE-IMPLEMENTATION REPO STATE
2. FILES INSPECTED
3. FILES MODIFIED
4. EXACT CHANGES MADE
5. VALIDATION PERFORMED
6. COMMIT HASH + MESSAGE
7. PUSH RESULT
8. NON-CLAIMS
9. RESIDUAL RISKS
10. STATUS
