# VSM Store Procedure — Controlled Rollout

## Required behavior

- Definir release set.
- Definir entorno.
- Definir ventana.
- Definir usuarios/repartidores incluidos.
- Definir rollback.
- Definir métricas.
- Preservar non-claims.

## Output

1. ROLLOUT TARGET
2. RELEASE SET
3. ENTRY CRITERIA
4. MONITORING PLAN
5. ROLLBACK PLAN
6. STOP CONDITIONS
7. NON-CLAIMS
8. GO / NO-GO
