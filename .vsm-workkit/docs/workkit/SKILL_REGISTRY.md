# VSM Store - Skill Registry

Compact metadata layer for the current Ya VOY Skill System v2 procedures.

This registry is metadata for active repo procedures. It does not add hooks, CI, runtime enforcement, product behavior, DB/Auth/Supabase/browser/provider proof, or production readiness. Skills are procedural, not authoritative: they narrow execution and never expand the prompt's explicit scope.

Codex is the only real target tool. Role labels:

- `Codex, rol Anty`: implementation/executor/code-changing lanes.
- `Codex, rol Codex`: readiness, audit, acceptance, canon, and read-only QA lanes.
